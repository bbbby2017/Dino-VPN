Clash Verge Rev

跨平台代理客户端

把复杂网络配置
变成清爽桌面体验

一个基于 Tauri 与 Rust 的 Clash Meta 图形界面，面向 Windows、macOS 和 Linux 用户。

产品介绍 · 8 页
开场可以把它定位成“给普通用户使用的 Clash Meta 桌面控制台”。不要先讲内核、规则、TUN 这些术语，先讲它解决的是日常使用代理时的繁琐问题。

它是什么

一站式管理代理、配置与网络模式

Clash Verge Rev 把订阅导入、节点选择、系统代理、TUN 模式、规则管理和更新维护集中在一个桌面应用里。

可视化 跨平台 内置 mihomo 配置可同步
这一页用一句话帮用户建立心智：它不是“另一个配置文件编辑器”，而是一个把日常代理操作集中起来的桌面应用。

01 · 快速上手

下载安装后，几步就能开始使用。

1

选择对应系统安装包

支持 Windows、Linux 和 macOS 11+，普通用户直接从 Release 页面下载即可。

2

导入订阅或本地配置

配置文件集中管理，后续更新、切换、增强都在应用内完成。

3

打开系统代理或 TUN 模式

按使用场景选择更轻量的系统代理，或覆盖更完整网络流量的 TUN 模式。

这一页重点讲“门槛低”。用户不需要理解所有网络细节，也可以按安装、导入、开启三个动作完成第一次使用。

02 · 核心体验

常用操作，尽量都放到眼前。

节点与代理组

通过图形界面选择节点、切换策略组，减少手改 YAML 的成本。

流量与连接状态

查看网络流量、连接情况和运行状态，排查问题更直观。

托盘与快捷操作

日常开关代理、切换模式、查看状态，可以更贴近桌面使用习惯。

这里不要陷入技术细节，强调“用户能看见、能点、能控制”。它把原来隐藏在配置和命令里的动作变成了界面操作。

03 · 配置管理

订阅、规则和增强配置，都有地方放。

Y

配置文件管理

集中维护多个配置，适合不同网络环境或不同服务来源。

M

Merge / Script 增强

在不破坏原始订阅的前提下，按自己的习惯做规则和字段增强。

E

编辑提示

内置编辑能力与语法提示，让高级用户也能更安心地调整配置。

这一页的表达要兼顾普通用户和进阶用户。普通用户听到“订阅能管理”，进阶用户听到“Merge 和 Script 可增强”，两类人都能找到价值。

04 · 视觉与个性化

不是只“能用”，也要每天看着舒服。

深浅色界面与主题定制

支持自定义主题颜色、代理组图标、托盘图标和 CSS Injection，让工具融入自己的桌面环境。

产品介绍里这页可以稍微停一下，因为截图比文字更容易让普通用户感知“这是一个成熟桌面应用”。如果现场打开演示，也可以从这页切到真实应用。

05 · 多端与备份

换设备，也不用从零开始。

W

WebDAV 备份与同步

把配置备份到自己的云端空间，多台设备之间更容易保持一致。

U

内置更新体验

应用、内核和相关能力持续维护，适合长期作为日常网络工具使用。

普通用户最怕的是“换电脑又要重新配”。这一页强调可备份、可同步、可维护，给用户长期使用的信心。

为什么选择它

更少折腾，
更多掌控。

Clash Verge Rev 适合希望稳定使用代理、又不想长期手动维护复杂配置的桌面用户。

适合这些场景

  • 日常代理与节点切换
  • 订阅配置长期维护
  • 需要 TUN 模式的复杂网络环境
  • 多设备备份与同步
